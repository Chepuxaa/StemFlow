StemFlow for Windows x64 - alpha

Run StemFlow.exe. Only one EXE is needed; no Python installation, separate
worker or _internal folder. The GUI requires Microsoft Edge WebView2 Runtime.

Download the model when prompted (1.92 GB), with progress and SHA-256 checks.
Setup also downloads the audio tool (about 31 MB). Choose a destination, add
tracks and start the queue. Load .stem.mp4 files into Traktor Pro 4.

GPU: TensorRT for RTX with a compatible NVIDIA RTX card and driver.
CPU: ONNX Runtime. Fast CPU is enabled by default; disable for original precision.
PyTorch and the full CUDA Toolkit are not required.

First GPU use prepares an engine. First Fast CPU use prepares a local cache
(about 0.94 GB); INT8 can slightly change audio. CPU is considerably slower.
Models, engines and settings are in %LOCALAPPDATA%\StemFlow.
The embedded runtime temporarily extracts at launch; allow free disk space.
