StemFlow for Windows x64 - alpha build

1. Extract the entire ZIP. Keep StemFlow.exe, StemFlow-worker.exe and _internal together.
2. Open StemFlow.exe. It checks the model and offers a 3.76 GB download if needed.
   Download progress, speed, integrity verification and cancellation are built in.
3. Choose a save folder and add tracks. Download-model.cmd is an optional CLI alternative.

Python is included in the application bundle. The GUI requires Microsoft Edge
WebView2 Runtime. CUDA requires a compatible NVIDIA driver; CPU mode is available.
Settings, model weights and reports are stored in %LOCALAPPDATA%\StemFlow.
Do not copy only the EXE: its _internal runtime is required.

Source and instructions: https://github.com/Chepuxaa/StemFlow
Developer and designer: @Chepuxaa
Built with assistance from OpenAI Codex.

This alpha was checked on the development Windows PC: GUI startup, CUDA/CPU
separation, CPU fallback, queued tracks and model reuse. It still needs testing
on a clean Windows installation and with your own music in Traktor.
